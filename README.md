# Md. Shamim Miah — Professional Portfolio

GitHub Pages website for Md. Shamim Miah.

## Upload these 6 files directly to the repository root
- `index.html`
- `style.css`
- `script.js`
- `README.md`
- `profile.png`
- `Md_Shamim_Miah_CV.pdf`

No `assets` folder is required in this version.

## Publish
1. Upload all six files to `miahsham1988-svg.github.io`.
2. Commit the changes to the `main` branch.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Visit `https://miahsham1988-svg.github.io`.
